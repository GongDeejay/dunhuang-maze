# 第一关打磨：古道上的足迹

## 体验目标

第一关从大范围随机搜集，改为紧凑的寻亲旅程：足迹 → 有代价的选路 → 可选探索 → 找到妈妈 → 开捷径回营地。保留即时制战斗、现有角色美术、移动输入、加载前情和锁定的 Godot 引擎缓存。

- 17 × 13 的手工骨架，只有非关键小岔路随机变化，不会把剧情节点生成到死路之外。
- 古道较长、无风沙伤害，有一次性清泉；近路较短，有四格风沙和沙蝎。路牌在选择前解释代价，也允许折返。
- 石窟支路可以完全跳过；探索后获得一次性恢复和本关视野 +1。
- 三只沙蝎限制在各自遭遇区，出生点、路牌和清泉附近不会被远处敌人追入。
- 剧情卡片打开时，玩家操作、攻击冷却、敌人移动及攻击暂停；关闭后继续。新探索不再被误判为迷路。
- 找到妈妈后恢复体力，开启右侧返程捷径并更新目标；到营地显示步数和探索结果，用大按钮继续第二关。
- 为避免后续重复寻找已救出的家人，第二、三关目标分别对应哥哥和弟弟；其地图生成、尺寸、敌人密度和战斗机制保持不变。

## 实现位置

- `scripts/first_journey.gd`：关卡骨架、固定遭遇、一次性事件与捷径。
- `scripts/presentation/journey_card.gd`：自适应剧情卡片。
- `scripts/main.gd`：暂停输入/战斗、目标、剧情与通关衔接。
- `tests/test_runner.gd`：24 个随机种子的可达性、路线差异、奖励幂等性、捷径、输入暂停与跨关重置测试。

## 验证

运行 `BECKETT_ENABLE=0 ./run_tests.sh` 与 `python3 -m unittest discover -s tests -p 'test_web_export.py'`。本次分别为 577 项断言通过、5 项通过。

浏览器全流程测试用 `tests/first_journey_probe.tscn` 作为**独立测试副本**的主场景导出，再用本地 HTTP 服务运行 `tools/verify_first_journey.mjs`。该探针只读游戏状态，移动、选难度、关闭卡片均通过真实键盘或触屏事件，不直接修改游戏状态。生产导出继续排除 `tests/**`，不得将测试副本作为发布包。

已验证 1440 × 900 桌面、390 × 844 手机、360 × 640 小屏、360 × 640 / 20px 浏览器大字号、844 × 390 横屏：

- 普通难度下，古道 + 石窟和不探索石窟的风沙路线都可生存通关。
- 每次方向输入最多移动一格；读卡片超过敌人行动间隔，敌人仍不行动。
- 所有剧情卡片均在可视窗口内，截图经人工检查。
- 找到妈妈、捷径开启、营地通关、大按钮进入第二关的状态都正确。
- 无浏览器 `pageerror` / `console.error`。

另运行 `tools/verify_responsive_web.mjs` 与 `tools/verify_loading_intro.mjs` 回归现有布局和加载前情。

## 接下来的试玩观察

自动化通关只证明流程正确，不能证明节奏有趣。请用新旅程分别尝试古道与近路，观察：

1. 第一次到路口是否能理解两条路的代价？
2. 提示是否过密、打断探索？
3. 石窟奖励是否值得绕路，沙蝎是否过弱或过强？
4. 找到妈妈后，是否自然理解要去营地？
5. 第一关到第二关的难度增幅是否过陡？

暂不承诺固定通关时长，也不扩展装备、经济或后续地图系统；根据真实试玩反馈再决定下一轮调整。

## 2026-11-04：壁画路书与鹿形路标

本轮沿用三兔切片的“加载时留悬念 → 场景里认出线索 → 看得见的寻路帮助”，不新增答题、任务清单或收集门槛。

- 石窟原有补给、视野 +1 保留；原剧情卡换成妈妈的路书。纸上是当前关卡真实的石窟—古道—石门路线，点击石门即可将该段路线描成地图金线，不用记密码或再做一道测试。
- 可以收起后继续赶路，也可以随时用按钮 / F 回看。阅读时冻结移动与战斗；触控关闭不会把同一次输入透传为走路。
- 金线仅展示局部可走路线，不揭露未见敌人、家人和出口，不改变墙体、伤害、补给或救援门槛。走到石门后目标自然切换为向北寻找妈妈。
- 清泉前增加鹿形路标，使用原有一次性恢复 6 点体力的事件承接九色鹿故事，不叠加新奖励。
- 加载页配图为原创小型内联 SVG，不增加图片请求。《五台山图》与虚构敦煌路书、九色鹿故事与虚构泉水路标明确区分。

开发位置：`scripts/travel_lore.gd`、`assets/lore/*.json`、`scripts/presentation/route_notebook.gd`、`route_sketch.gd`。加载页和游戏共用文案源，避免两处叙事漂移。

逻辑回归已覆盖 24 个种子的路线连通、避开风沙、重复领取、关闭未描图、回看、读图冻结、跨关重置；本轮总计 1941 项断言通过，Web 构建测试 7 项通过。浏览器用只读探针与实际键盘 / 触控操作验收，不向生产加入跳关入口。
