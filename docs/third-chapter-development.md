# 第三关 3D 终章开发记录

## 范围与质量门槛

2026-09-20。仅第三关切换为轻量第一人称沙漠探索，新增全家团聚结尾。前两关地图、操作、美术、引擎版本和部署缓存不变。借鉴沙漠的轮廓、光线与空间反差，不复制 Journey 的角色或资产。

采用 Godot 原生 Compatibility 3D、程序生成低多边形场景、既有角色平面图。无跳跃、复杂地形物理、骨骼、视频或新运行时依赖。剧情不是护送任务，避免家人寻路卡住。

- [x] M2：完整第三关——沙谷/石窟/山口，路线选择、可选发现、轻量即时遭遇、寻找弟弟、返程捷径。

## 必测风险

1. 手机方向摇杆/观察/按钮分别拥有触点；松手、暂停、失焦后清除输入，不串触。
2. 不穿墙、不穿越未开启捷径；对角移动不加速，低帧率不跨过碰撞。
3. 互动须在范围和朝向内且没有墙阻挡；路线与奖励均可选，不产生软锁。
4. 战斗在暂停/剧情/后台冻结；失败回本关安全检查点，无长距离死亡跑图。
5. 3D 不捕获前两关输入；离开时释放鼠标和渲染比例，释放所有场景节点。
6. Web 使用原引擎散列；资源增长控制在现有 2 MB PCK 发布上限内。若超限，先缩减内容，不默默增加首屏大资源。
7. 桌面争取 60 FPS、手机争取 30 FPS；浏览器模拟触控只能验证逻辑与布局，不冒充真机 GPU 性能测试。

## 可重复验收

先安装与锁文件一致的 Godot 4.7 及 Web 模板，Node 环境需可解析 `playwright`。浏览器脚本使用本机 Chrome。

```sh
BECKETT_ENABLE=0 ./run_tests.sh
python3 -m unittest discover -s tests -p 'test_web_export.py'
python3 tools/export_browser_probe.py third
python3 -m http.server 8063 --bind 127.0.0.1 --directory artifacts/third-probe-export
```

另一个终端运行 `node tools/verify_third_chapter.mjs`。可用 `URL` 指定测试站点、`PROFILE` 单独复测一个配置。第一关使用 `python3 tools/export_browser_probe.py first`，在 8062 端口服务对应目录，再运行 `node tools/verify_first_journey.mjs`。

构建器在独立临时副本中修改入口，绝不修改正式 `project.godot`；所有 `tests/**` 均排除在正式包外。测试入口仅用于验收，不上传生产服务器。

## 2026-11-04：金光寻路可选探索

承接加载异闻中的建窟传说，以虚构的弟弟涂鸦实现“换个角度发现足迹”，不解释传说的历史成因，也不更改原地图和营地救援流程。

- 先读原有旅行手记，仍只恢复原先的 6 点体力。左移半步观察岩缝暖光时，原互动按钮变为“看看光里的脚印”；不要求精确像素对准，无计时惩罚。
- 点击后岩壁涂鸦与古道上的金色足迹同时显现，连接现有手记位置与弟弟石窟。足迹不穿墙、不经过风沙捷径，也不自动救援或开门。
- 找到弟弟后足迹隐藏，回程继续用原高塔地标；结尾增加一句回应这次发现。不探索同样可以正常通关。
- 暖光使用无光照材质的小石刻，不增加动态光源或后处理；整段足迹用一个 MultiMesh 绘制。加载页插图不以巨大悬浮图片放进 3D 场景。
- 浏览器截图验收发现近距离原手记标牌过大，已仅缩小这一处标牌；人物、其他世界标牌、战斗和移动数值不变。

新增逻辑测试覆盖前置手记、观察范围 / 朝向、奖励幂等、原救援门槛、路线连通和返程切换。全量 1941 项断言、7 项 Web 工具测试通过；既有 headless 退出资源警告仍保留记录，不宣称零警告。

最终本地验收：6 个浏览器配置通过，桌面与手机完成线索、救援、返程、结尾与清档。截图检查后将暖光移到左侧观察点正前方，额外完整复测 `phone-gold`，并断言可互动时暖光位于相机视锥内，避免竖屏只能看见按钮却看不到线索。证据位于 `artifacts/third-chapter-verify/`。这些是 Chrome 模拟触控检查，不是真机性能或 Safari 验收。

## 2026-11-04：入口 → 岔路 → 金光点视觉切片

范围：仅第三关入口、避风岔路至金光点及其可见远景。未改地图、墙体碰撞、路线、人物图、战斗数值、救援门、前两关玩法、运行时锁或部署配置。

- **入口**：去掉遮挡远景的装饰门梁；规则柱状岩体换为连续分层砂岩，加入轮廓远山、贴地碎石和原有足迹。岩壁向原碰撞外侧生长，不挤占通道；相邻段使用共享的世界坐标高度以接顺轮廓。
- **岔路**：悬浮大字改为两块实体木路牌；避风侧增加小石堆，石路接缝弱化。进入左侧弯道时环境光略冷、风声降低，走向金光时恢复暖色；离开切片后恢复原环境参数。教学提示结束后隐去闲置提示条，触控和互动按钮保留。
- **金光点**：矩形立柱改成落地的浅浮雕岩片、细岩缝和一小片暖光；保留原观察位置与宽松判定。岩片向场景深处退，避免占满手机竖屏。发现后岩面小脚印显现，地面足迹在 0.9 秒内逐段亮起；不强制转镜头、不移动玩家、不额外回血。暂停冻结动画，救援后不重新亮起旧路线。
- **性能**：程序生成低多边形，砂岩按 16 米空间块合批；足迹仍为一个 MultiMesh。仅一片局部透明暖光，不引入新纹理、模型下载、动态灯、阴影贴图或体积雾。原引擎文件名保持锁定。

验收增加原 RNG 墙高／位置逐一比对、新装饰零碰撞、几何与分块预算、切片外光照恢复、教学文字隐去、脚印渐显／暂停／幂等、手机可见性及发现过程不接管镜头。浏览器脚本新增避风弯道截图，继续串行跑桌面、竖屏触控、小屏大字号、横屏与旋转。

走查迭代记录：修正三角面绕序造成的明暗反向、岩段接缝、岔路浮字过大、近距离金光岩片遮满竖屏；以上均通过渲染截图发现，未通过修改玩法断言掩盖问题。视觉证据保存在 `artifacts/third-chapter-verify/`，旧画面对照在 `artifacts/valley-before/`。
