# 第三关 3D 终章开发记录

## 范围与质量门槛

2026-09-20。仅第三关切换为轻量第一人称沙漠探索，新增全家团聚结尾。前两关地图、操作、美术、引擎版本和部署缓存不变。借鉴沙漠的轮廓、光线与空间反差，不复制 Journey 的角色或资产。

采用 Godot 原生 Compatibility 3D、程序生成低多边形场景、既有角色平面图。无跳跃、复杂地形物理、骨骼、视频或新运行时依赖。剧情不是护送任务，避免家人寻路卡住。

## 里程碑

- [x] M1：可玩切片——浏览器能显示真 3D，连续移动、碰撞、观察和暂停；首测锁定引擎仍能导出。
- [x] M2：完整第三关——沙谷/石窟/山口，路线选择、可选发现、轻量即时遭遇、寻找弟弟、返程捷径。
- [x] M3：结尾——团聚、原旅行合照、跳过/返回/确认重玩；存档与前两关衔接。
- [x] M4：本地验收——逻辑测试、真实浏览器按键与多点触控、横竖屏/大字号截图、前两关回归与包体检查。正式部署结果见下方发布记录。

## 必测风险

1. 手机方向摇杆/观察/按钮分别拥有触点；松手、暂停、失焦后清除输入，不串触。
2. 不穿墙、不穿越未开启捷径；对角移动不加速，低帧率不跨过碰撞。
3. 互动须在范围和朝向内且没有墙阻挡；路线与奖励均可选，不产生软锁。
4. 战斗在暂停/剧情/后台冻结；失败回本关安全检查点，无长距离死亡跑图。
5. 3D 不捕获前两关输入；离开时释放鼠标和渲染比例，释放所有场景节点。
6. Web 使用原引擎散列；资源增长控制在现有 2 MB PCK 发布上限内。若超限，先缩减内容，不默默增加首屏大资源。
7. 桌面争取 60 FPS、手机争取 30 FPS；浏览器模拟触控只能验证逻辑与布局，不冒充真机 GPU 性能测试。

## 可重复验收

先安装与锁文件一致的 Godot 4.7 及 Web 模板，Node 环境需可解析 `playwright`。浏览器脚本使用本机 Chrome。

```sh
BECKETT_ENABLE=0 ./run_tests.sh
python3 -m unittest discover -s tests -p 'test_web_export.py'
python3 tools/export_browser_probe.py third
python3 -m http.server 8063 --bind 127.0.0.1 --directory artifacts/third-probe-export
```

另一个终端运行 `node tools/verify_third_chapter.mjs`。可用 `URL` 指定测试站点、`PROFILE` 单独复测一个配置。第一关使用 `python3 tools/export_browser_probe.py first`，在 8062 端口服务对应目录，再运行 `node tools/verify_first_journey.mjs`。

构建器在独立临时副本中修改入口，绝不修改正式 `project.godot`；所有 `tests/**` 均排除在正式包外。测试入口仅用于验收，不上传生产服务器。
