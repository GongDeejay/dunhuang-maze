## 1. 产品目标与边界

让“记住线索”产生看得见的结果：拿到通行牌、读懂纹样、点亮归途。玩家首先是在寻找家人，不是在被迫完成认知测验。

- 每关一个主记忆机关，剧情版约 45–90 秒，先演示一轮，再让玩家操作。
- 机关位于安全区域；打开面板即暂停敌人、移动和第一人称镜头。关闭后恢复，不扣血、不消耗关键道具。
- 失败给解释与重试；两次失败主动提供提示、降低负荷或绕路。奖励是补给、捷径或方向提示，不能永久卡住团聚结局。
- 通关后在营地提供可选练习，每次一个短区块；不强推连续训练、排行榜或“脑龄”。
- 保留已经完成的第三关救援逻辑：救到弟弟后原来的回程门照常打开。新机关只能增加可选捷径/信标，不能把原有终点重新锁住。

## 2. 三个场景的具体落地

| 场景 | 机关与对应方法 | 玩家怎么做 | 世界中的反馈 |
| --- | --- | --- | --- |
| 戈壁古道 | 驿站补给账：复杂跨度 | 判断一笔简单账目，再记一个符号；交替数轮后按顺序交还符号 | 获得古道通行牌，打开补给间/近路 |
| 莫高窟 | 守护纹样：视觉变化检测 | 看一组纹样，短暂遮挡后判断指定位置是否改变 | 获得纹样印记，显出家人留下的路线 |
| 三危山 | 归途信标：N-back | 连续观察信标，判断当前符号是否与 N 个之前相同 | 点亮营地方向，开启额外避风捷径 |

### 第一关：驿站补给账（OSPAN 启发的复杂跨度）

情境：风暴打乱了驿站的补给牌，守站人请玩家核账、整理路签。

1. 演示“3 袋 + 2 袋 = 5 袋？”；点击“对 / 不对”。
2. 随后呈现一个与答案无关的路签，例如“日”。路签收起，再进行下一笔账和下一个符号。
3. 剧情版从 2 个符号开始，再试 3 个：例如“日 → 月 → 山”。
4. 最后从大按钮中按顺序选择路签；提交后解释错在第几位。不能把前面的符号一直留在屏幕上。
5. 成功获得通行牌；需要帮助时守站人可展示第一张牌，或允许走原来的普通路线。

关键点：必须保留“判断账目”和“保持符号序列”的交替，否则只是顺序记忆。算术只做轻度干扰，不用乘除难题筛掉孩子。正式练习先校准能理解的账目难度，再逐区块调整符号数量，不能两者同时升级。我们自行设计素材，不移植实验软件或宣称这是标准 OSPAN。

成绩分开显示：**顺序位置正确的项目数 / 总项目数**、全对序列比例、账目判断正确率和反应时。使用过提示的轮次标注“辅助完成”。不以一次偶然通过的最长序列代替完整跨度成绩。[Engle 实验室：任务及计分说明](https://englelab.gatech.edu/faq)

### 第二关：守护纹样（视觉变化检测）

情境：在洞窟外的纹样复刻展示板上帮助整理图案线索。不是触摸、破坏真实壁画来开门。

1. 先看 3–4 个位置上的简单纹样，用形状区分，不只依赖颜色。
2. 剧情示例展示约 800–1000 毫秒，遮挡 1000 毫秒。
3. **只在一个明确标记的位置呈现一个探测纹样**，其他位置不再展示。玩家选“没变 / 变了”。
4. 变化与不变都出现，避免“每轮都找不同”。剧情初始可设 8 题中完成 6 题获得印记；这是待试玩调整的游戏门槛，不是心理学常模。
5. 失败可重看、减少一个位置；印记显出通往家人的足迹或打开可选近路。

练习每个区块固定图案复杂度、呈现时间和位置数；只在区块间调整数量。先用较长展示时间保证手机看清，再另设短呈现挑战；不把 100 毫秒当作所有设备必须达到的标准。

量化：同一阵列大小 N 下记录命中率 H（变化时答变）和虚警率 F（不变时答变）。此处特意选择**单位置探测**，对应 `K = N × (H − F)`；整屏变化任务的模型公式不能直接混用。K 依赖实验条件和模型，剧情 8 题不足以稳定估计容量，只显示答题结果。以后固定规则挑战积累足量试次、检查数据质量后，才考虑展示带条件说明的 K；不把“3–4”当所有年龄的及格线。[Rouder 等，2011：变化检测中的容量估计](https://link.springer.com/article/10.3758/s13423-011-0055-3)

### 第三关：归途信标（N-back）

情境：第一人称登上安全观景台，开启静止的二维信标面板。远处营地的符号依次亮起，需要辨认回声规律。

1. 先用 1-back 演示“当前是否与上一个相同”，确认玩家理解。
2. 可选 2-back：“日 → 月 → 日”，第三个“日”与两个之前相同；不是“以前见过就按”。
3. 每个符号初始约 2.5 秒，使用两个同等显眼的按钮“相同 / 不同”，电脑与触屏都可操作。
4. 最前面 N 个是建立序列的准备项，不计分。剧情可先试 12 个有效判断，9 个正确作为可调奖励门槛；困难时降到 1-back。
5. 点亮营地、给出归途方向或打开额外避风近路。随时退出，不影响原有救援和结尾。

序列由生成器控制目标与非目标比例，避免一直按同一个按钮过关；练习版可加入相邻位置重复但不符合 N-back 的干扰项，并记录其类型。

量化：按 N 分组展示正确率、正确反应的中位反应时、漏答率；另记命中、漏报、虚警、正确拒绝。双按钮任务中“没点”是漏答，不能自动算作正确的“不同”。试次足够且质量合格时再计算 d′；它反映信号辨别能力，不等于记忆容量。[Kane 等，2007：N-back 的效度研究](https://pubmed.ncbi.nlm.nih.gov/17470009/)

## 3. 游戏成绩、练习与评估分开

| 模式 | 规则 | 结果如何表达 |
| --- | --- | --- |
| 剧情机关 | 短、可求助、可绕路 | “独立完成 / 提示后完成”，奖励照常兑现 |
| 营地练习 | 区块内固定，区块间自适应 | 同任务、同难度下的准确率与速度趋势 |
| 固定规则挑战（后续） | 固定难度/时序，无提示，独立题序 | 条件明确的任务表现；未经验证不称标准化评估 |

三种任务不能直接相加成为“工作记忆总分”：复杂跨度和 N-back 的关联并不足以让它们互相替代，视觉变化检测又更偏向视觉保持。更合适的是三项独立表现卡片，展示条件、试次数和是否获得帮助。[Redick 与 Lindsey，2013：元分析](https://pubmed.ncbi.nlm.nih.gov/23733330/)

训练能让人更熟悉这些任务，但不能据此承诺提升智商、学业或日常能力，更不作为 ADHD 等疾病的筛查/治疗工具。若未来要作认知产品宣传，需要目标人群的信效度、常模和适当对照研究。[Melby-Lervåg 等，2016：工作记忆训练元分析](https://ora.ox.ac.uk/objects/uuid%3Adaa9a729-f17b-4e45-97c0-cff5075ea404)

### 难度与数据质量的实施约定

- 可先试“连续两个区块 ≥85% 升一级，≤60% 降一级”，其他保持；这是产品调参起点，须试玩修订，不是学术规定。剧情版永远允许求助。
- N、呈现时间、干扰难度、图案复杂度每次只改一个。不同 N 或不同设备的反应时不直接排名。
- 记录任务/规则版本、题序种子、设备和输入类型、N/跨度、实际呈现与反应时间、答案、辅助状态、中断标志。默认仅保存在本机；本次不增加云端采集。
- 图案在试次开始前加载完毕；用单调时钟记录实际绘制后的事件时间。页面失焦、切后台、改变窗口导致布局重排时中止当前试次，不把卡顿算作认知错误。普通浏览器不能保证实验室级的 100 毫秒呈现精度。
- K 按同 N、同条件汇总；保留原始 H/F 和负估计，标注数据不足或不稳定，不强行输出“容量为零”。漏答多、处理中断多时不出能力解释。
- d′ 极端比例采用明确的修正，例如 `H*=(命中+0.5)/(目标数+1)`，`F*=(虚警+0.5)/(非目标数+1)`，再算 `Z(H*)−Z(F*)`。只对有效回答汇总并单列漏答，拒绝把样本很少的高分解释为能力优势。[Hautus，1995：极端比例修正](https://doi.org/10.3758/BF03203619)
- 重测换等价题序，并注明熟练/练习效应；自适应练习与固定挑战不能混在一条能力趋势线上。

## 4. 开发顺序与验收

建议先做一个**莫高窟纹样机关的可玩原型**：视觉直观、文化主题贴合、对现有战斗和 3D 控制的侵入最少。确认“有趣且不烦”后再铺开三关，而不是一次塞进三个考试面板。

1. 讨论确认：第二关是否改名与美术换装、剧情机关是否可绕路、面向的年龄段、是否需要独立练习入口。
2. 原型：共享机关状态机（说明→演示→呈现→作答→反馈→奖励），先接一个纹样机关；可用功能开关整体关闭。
3. 试玩：先找约 8–12 位目标玩家检查理解、卡住位置和乐趣。这是可用性检查，不是建立认知常模。重点看是否能说清规则、主动重试、求助和退出比例。
4. 扩展：补给账与信标分别验证；最后才加入本机练习记录，不在剧情阶段要求登录/收集健康数据。

验收门槛：

- 说明与一次演示后，玩家能复述规则；普通难度单机关控制在约 90 秒以内。没有失败扣血、重复刷奖励、重进后门重新锁死或永久卡关。
- 手机按钮至少约 48 CSS px 等效触达区域；不依赖拖拽、颜色、闪烁或音频。系统大字号下答案与退出按钮始终可达。
- 单元测试覆盖跨度序位计分、N-back 准备项/干扰项、H/F 分母、漏答、提示与独立完成分离、奖励幂等及存档恢复。
- 桌面/手机实测开始、暂停、退出、重试、切后台和大字号；第三关机关关闭后不能遗留鼠标捕获或虚拟摇杆按下状态。
- 回归现有三关救援、通关和结尾；引擎地址与首次加载体积预算不变。没有新增外部图片/字体下载阻塞试次。

## 5. 地理表达

“戈壁、莫高窟、三危山”是本产品的场景组织，不声称复刻真实旅游路线。莫高窟介绍聚焦壁画、彩塑与丝绸之路文化交流；三危山与莫高窟遥对的关系用于串联旅程。谜题都是虚构体验，文物展示采用复刻板。[敦煌研究院：莫高窟](https://www.dha.ac.cn/info/1425/3659.htm)
