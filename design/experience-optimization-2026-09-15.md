# 体验优化与自动部署验收

## 已实现

- 即时战斗：玩家朝相邻敌人方向攻击，0.35 秒攻击间隔；敌人独立计时行动并预告方向，玩家可后退躲避。
- 修复角色与敌人重叠、攻击立即触发反击、敌人移动未立即重绘的问题。
- P / Esc 与触屏暂停按钮；失去窗口焦点自动暂停，返回后手动继续。
- 分阶段目标提示、遇敌/道具提示、长时间未找到家人后的方向辅助。
- 桌面背包命中区、难度卡片命中区、可点击的切换难度确认弹窗。
- 手机按浏览器实际尺寸布局，修正 HUD 重叠、控制区越界及地图边缘大量空白。
- 将保存提示明确为“关卡检查点，从本关重新开始”。

## 首次加载

旧本地导出的 PCK gzip 约 7.94 MB；优化后约 0.50 MB。原因主要是删除运行包中的全量中文字库，替换为约 200 KB 的游戏文字子集。

WASM gzip 仍约 10.05 MB。WASM + PCK 合计从约 18 MB 降至约 10.55 MB，下降约 41%。这是文件体积对比，并非线上加载秒数的测量。

导出脚本增加中文加载进度、资源预加载与预压缩。CI 使用版本化文件名，资源先上传、入口最后发布，并保留旧资源。

## 验证

- 本地与无 Godot 缓存的干净目录：164 项测试通过。
- 新增即时战斗回归检查：不重叠、不即时反击、攻击间隔限制。
- 浏览器 1280×720 和 390×844：启动、难度选择、手机 HUD、暂停、菜单、切换难度确认通过人工交互检查。
- 修复过程中捕获的脚本解析错误已消除；最终浏览器运行未发现新增 console error。
- 测试退出时仍有原有对象/资源清理告警，断言全部通过。

## 自动部署

检查时远端默认 main 无工作流，当前分支已有的 Web Export Check 仅用于导出。新增 Build and Deploy Web 工作流，push main 自动测试、导出并上传构建产物。

生产发布还需配置 `TENCENT_CVM_SSH_KEY`，以及一次性应用本站 Nginx 预压缩/缓存规则。Secret 缺失时工作流会明确警告并跳过生产发布。详见 `deploy/DEPLOY.md`。
