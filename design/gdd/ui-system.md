## 1. Overview

敦煌迷途采用**自适应UI系统**，根据设备类型和屏幕方向自动调整布局。

**设计目标**：
- 移动端：触摸友好，大按钮，清晰信息
- PC端：信息密集，键盘操作
- 自适应：根据屏幕比例自动切换布局

## 3. UI Components

### 3.1 心形血条

| 位置 | 样式 | 说明 |
|------|------|------|
| 竖屏：左上角 | 5个心形图标 | 满血=实心，空血=空心 |
| 横屏：左上角 | 5个心形图标 | 同上 |
| PC：信息栏 | 数字显示 | HP: 18/18 |

### 3.2 方向控制

| 模式 | 控件 | 尺寸 |
|------|------|------|
| 竖屏 | 虚拟D-pad | 1.2倍标准尺寸 |
| 横屏 | 虚拟D-pad | 0.7倍标准尺寸 |
| PC | 键盘WASD/方向键 | - |

### 3.3 功能按钮

| 按钮 | 功能 | 快捷键 |
|------|------|--------|
| E | 使用道具 | E键 |
| R | 重新开始 | R键 |
| Q | 返回主菜单 | Q键 |

### 3.4 信息显示

| 信息 | 位置 | 字体大小 |
|------|------|----------|
| 家人进度 | 底部左侧 | 2×标准 |
| 步数统计 | 底部左侧 | 2×标准 |
| 战斗日志 | 底部 | 标准 |
| 地形名称 | 信息栏 | 标准 |

## 4. Font Scaling

### 4.1 缩放公式

```gdscript
font_scale = clampf(min_dim / 200.0, 1.0, 3.0)
```

| 屏幕短边 | font_scale | 字体大小 |
|----------|------------|----------|
| 200px | 1.0 | 标准 |
| 400px | 2.0 | 2倍 |
| 600px | 3.0 | 3倍 |

### 4.2 按钮尺寸

```gdscript
btn_radius = clampf(min_dim * 0.07, 28.0, 50.0)
func_btn_size = clampf(min_dim * 0.09, 36.0, 55.0)
```

## 6. Implementation Notes

- 移动端控件：`MobileControls` (extends Node2D)
- PC端信息栏：`UIPanel` (extends RefCounted)
- 字体缩放：基于屏幕短边动态计算
- 触摸检测：扩大检测区域以适应手指操作
