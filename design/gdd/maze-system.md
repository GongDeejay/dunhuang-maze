## 1. Overview

敦煌迷途的迷宫系统采用**BFS路径连接+分支+环路**算法，确保：
- 每次游玩生成不同的迷宫布局
- 保证从起点到终点存在可达路径
- 提供多条探索路线

**设计目标**：
- 随机性：每次游玩都不同
- 可达性：保证存在有效路径
- 探索性：提供多条路线选择
- 难度递进：随关卡增加复杂度

## 2. Maze Generation Algorithm

### 2.1 BFS路径连接（主路径）

```
1. 在地图上随机放置N个路径点（waypoints）
2. 使用BFS连接相邻路径点
3. 确保起点(0,0)和终点(width-1,height-1)被连接
```

### 2.2 分支生成

```
1. 遍历所有已连接的格子
2. 15%概率尝试向未连接的邻居延伸
3. 延伸长度：3-6格
4. 避免回头（不走已走过的方向）
```

### 2.3 环路添加

```
1. 遍历所有墙壁
2. 12%概率移除墙壁，创建环路
3. 环路增加多条路线选择
```

### 2.4 后处理

```
1. 移除完全封闭的格子（0个开口）
2. 确保起点和终点有至少2个开口
```

## 4. Terrain System

### 4.1 地形类型

| ID | 名称 | 颜色 | 特殊效果 |
|----|------|------|----------|
| sand | 沙地 | 浅黄 | 无 |
| desert | 荒漠 | 深黄 | 移动伤害-1HP |
| grotto | 石窟 | 灰褐 | 视野限制 |
| oasis | 绿洲 | 绿色 | 恢复HP |
| ancient_road | 古道 | 棕色 | 无 |

### 4.2 地形生成

```
1. 使用FastNoiseLite生成双层噪声
2. 结合5个聚类中心点
3. 根据噪声值和距离分配地形类型
4. 起点固定为古道，终点固定为绿洲
```

## 6. Connectivity Guarantee

### 6.1 BFS连通性

```
BFS从起点(0,0)开始：
1. 将起点加入队列
2. 对每个可达格子，检查4个方向
3. 如果方向有通道且未访问，加入队列
4. 继续直到队列为空
5. 返回所有可达格子的集合
```

### 6.2 家人生成保证

```
生成家人时：
1. 获取所有可达格子
2. 只在可达格子中随机选择位置
3. 确保家人可以被玩家找到
```

### 7.2 墙壁绘制规则

```
- 只在无通道的方向绘制墙壁
- 边界始终绘制墙壁
- 墙壁厚度 = cell_size × 0.08
```

- 可达性检查：`get_reachable_cells()` in MazeGenerator
