## 1. Overview

敦煌迷途的怪物系统采用**地形关联+回合移动**机制。每种地形对应特定怪物类型，怪物在回合结束时移动，玩家可预判其行动。

**设计目标**：
- 地形决定怪物类型，强化探索决策
- 怪物移动可预测，支持策略规划
- 数值随关卡难度递增，保持挑战性

## 3. Monster AI

### 3.1 移动规则

```
回合结束时：
1. 检查玩家是否在相邻格
2. 如果是 → 攻击玩家
3. 如果否 → 随机选择一个可移动方向
4. 优先选择朝向玩家的方向（50%概率）
```

### 3.2 移动限制

| 限制 | 说明 |
|------|------|
| 墙壁 | 不能穿墙（除沙虫外） |
| 边界 | 不能移出地图 |
| 占用 | 不能移动到已被占据的格子 |
| 地形 | 部分地形限制移动（如绿洲减速） |

### 3.3 特殊能力

| 怪物 | 能力 | 触发条件 | 效果 |
|------|------|----------|------|
| 沙蝎 | 毒蜇 | 攻击命中 | 目标每回合-1HP，持续3回合 |
| 沙虫 | 钻地 | 随机 | 穿越相邻墙壁 |
| 石魔 | 岩甲 | 被攻击 | 减少50%伤害 |
| 水妖 | 水盾 | 被攻击 | 反弹25%伤害 |
| 盗匪 | 掠夺 | 攻击命中 | 随机偷取1个道具 |

## 5. Visual Design

### 5.1 怪物外观

每种怪物有独特的视觉特征：

| 怪物 | 外观特征 | 颜色 |
|------|----------|------|

| 状态 | 视觉效果 |
|------|----------|
| 正常 | 全色显示 |
| 受伤 | 闪烁红色 |
| 死亡 | 缩小消失 |
| 护盾 | 蓝色光环 |
| 毒状态 | 绿色粒子 |

## 6. Implementation Notes

- 怪物实体类：`MonsterEntity` (extends Node2D)
- 怪物生成：`entity_spawner.gd`
- 怪物AI：每回合结束时调用 `try_move()`
- 战斗系统：碰撞触发，单回合结算
