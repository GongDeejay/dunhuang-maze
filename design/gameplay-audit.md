## 三、数值与平衡观察

| 维度 | 观察 |
|------|------|
| 升级曲线 | Lv3 约 +4 HP / +2 ATK，相对怪物 scale 1.4 偏弱 |
| 怪物密度 | 第三关 12% ≈ 126 只怪 / 1050 格，偏高 |
| 道具密度 | 4% × 难度倍率，简单模式 6% 可能过丰 |
| 家人数量 | 关1=2, 关2=3, 关3=3，与 maze 规模增长不同步 |
| 洞窟视野惩罚 | -2/-3 已生效，但玩家难以感知（无 UI 提示） |
| 瓦罐 70% | 大量容器 → 开罐节奏重复 |
